# Week 1 – Responsive Landing Page

A responsive landing page created using **semantic HTML5, modern CSS, and vanilla JavaScript**.

## Project Structure

```text
week1-responsive-landing-page/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Features

- Semantic HTML5 structure
- Responsive desktop, tablet, and mobile layouts
- CSS Grid and Flexbox
- Mobile navigation menu toggle
- Accessible navigation attributes (`aria-expanded`, `aria-controls`)
- Smooth scrolling
- Responsive hero section and feature cards
- No external frameworks or dependencies

## How to Run

No installation is required.

1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For the best development experience, open the folder in VS Code and use a local server such as Live Server.

## Testing Checklist

- Desktop width: navigation and two-column hero should display correctly.
- Tablet width: hero should stack and feature cards should remain readable.
- Mobile width: hamburger button should open/close the navigation.
- Test portrait and landscape orientations.
- Check links, buttons, spacing, and text readability.
